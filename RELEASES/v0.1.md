# v0.1 — Initial release (2026-05-17)

Short summary
-------------
Initial public release of SpriteFetch — a Streamlit app to scan a web page, preview images, select assets, and export selected images as simple SVG files.

Key features
------------
- Scan a URL and discover image assets (scraping)
- Preview and select images to download
- Export selected images as SVG files with embedded base64 data (saved to `downloads/`)

Included
--------
- `app.py` — Streamlit application
- `requirements.txt`
- `README.md`
- `LICENSE`
- `assets/logo.svg`, `docs/ui-preview.png`

Quick start
-----------
1. Create a Python 3.10+ virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`
