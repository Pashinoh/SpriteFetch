# v0.1 — Initial release (2026-05-17)

Summary
-------

Initial public release of SpriteFetch. This release provides a Streamlit-based UI to scan a target web page for images, preview and select assets, and export selected images embedded inside simple SVG wrapper files.

Highlights
----------

- Streamlit UI with a favicon and pixel-art style.
- Image scraping using `cloudscraper` + `BeautifulSoup4`.
- Conversion/export: each selected raster image is embedded into a simple SVG wrapper (base64) and saved to `downloads/`.
- Included assets: `assets/logo.svg` and `docs/ui-preview.png`.

Included in this release
------------------------

- `app.py` — main Streamlit application
- `requirements.txt` — runtime dependencies
- `README.md` — usage and quickstart
- `LICENSE` — MIT
- `assets/logo.svg`, `docs/ui-preview.png`

How to use this release
-----------------------

1. Create a Python 3.10+ virtual environment.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the app: `streamlit run app.py`.

Notes for publishing on GitHub Releases
-------------------------------------

The repository already has a tag `v0.1`. To publish this release on GitHub:

1. Go to your repository → Releases → Create a new release.
2. Choose tag `v0.1` (or create it if absent).
3. Set the release title to `v0.1 — Initial release` and paste the contents of this file as the release notes.
4. Attach `releases/SpriteFetch-v0.1.zip` (created in the repository) as a binary asset for easy download.
