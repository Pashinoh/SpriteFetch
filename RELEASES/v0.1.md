# v0.1 — Initial release (2026-05-17)

Ringkasan singkat
-----------------
Rilis awal SpriteFetch — aplikasi Streamlit untuk men-scan halaman web, menampilkan preview gambar, memilih aset, dan mengekspor gambar sebagai file SVG sederhana.

Fungsi utama
-----------
- Scan URL untuk menemukan gambar (scraping)
- Preview dan pilih gambar yang ingin diunduh
- Ekspor gambar terpilih ke file SVG (embedded base64) di folder `downloads/`

Termasuk
-------
- `app.py` — aplikasi Streamlit
- `requirements.txt`
- `README.md`
- `LICENSE`
- `assets/logo.svg`, `docs/ui-preview.png`

Cara cepat
---------
1. Buat virtualenv Python 3.10+
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

Catatan untuk penerbitan
-----------------------
