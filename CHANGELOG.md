# Changelog

All notable changes to this project will be documented in this file.

## [0.2.0] - 2026-05-21

### Updated
- Multi-format export: SVG, PNG, JPG, WEBP
- Batch processing with ZIP download
- Keyword filtering with comma-separated terms
- UI polish and clearer button labels
- Better stability for large image sets

## [0.1.0] - 2024-01-15

### Added
- Initial release
- Web scraping and image extraction
- SVG conversion with embedded base64 encoding
- Streamlit-based web interface
- Cloudflare bypass capabilities
- Dark/light mode support
